# DeoCoach — Edition for African Coaches (v0.1)

From competencies to cheques. A single-page app (no build step) for coaches:

1. My profile · 2. Coach Signature · 3. Competency Ladder (L1–L5) · 4. Niche Radar (Year 1 / 2 / 5)
5. Competencies → Cheques (Offer Forge, Proof Vault, Cheque Tracker)
6. Brand Compass (career stage, selling heat map, 360° perception)
7. Brand Funnel (10 stages → brand journey level and leak point)
8. Stuck & 90-day plan (8 traps) · Client Toolkit · Opportunities & Networks · Supervisor Desk

Data stays in the visitor's browser (localStorage). Beta development tool — not a selection instrument.

Deploy: Vercel, framework preset "Other", no build command, output = repo root.
